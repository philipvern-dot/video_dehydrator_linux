HandBrakeCLI
  HandBrake, GPL-2.0. https://handbrake.fr/
  The installer uses the official Linux Flatpak fr.handbrake.ghb
  from Flathub. Running the installer again updates that Flatpak.
  Checked 2026-10-22: Flathub lists HandBrake 1.11.2.
  https://flathub.org/apps/fr.handbrake.ghb
  Source: https://github.com/HandBrake/HandBrake/archive/refs/tags/1.11.2.tar.gz

ffmpeg, ffprobe
  FFmpeg, GPL-3.0. See FFmpeg-LICENSE.txt after the installer downloads it.
  The installer downloads the johnvansickle static GPL build
  ffmpeg-release-amd64-static.tar.xz, or the arm64 archive, from
  https://johnvansickle.com/ffmpeg/releases/
  Checked 2026-10-22: that release archive is FFmpeg 7.0.2.
  Running the installer again replaces the tools when the installed
  ffmpeg -version line is not 7.0.2.
  The archive contains ffmpeg and ffprobe. It does not contain ffplay.
  Compare plays the new file's sound through the desktop audio.
  The source tree does not contain the binaries.
  The encode stays software x265.
  This build is separate from the Windows essentials build, FFmpeg 9.0.2.
